# 2026 LoL 世界賽分析（粉絲自製・非官方）

網站：https://ch3ngka1.github.io/lol-worlds/

- 賽程、比分、選手名單：每小時由 GitHub Actions 從 [Leaguepedia](https://lol.fandom.com/) 自動更新（`.github/workflows/update.yml`）。
- 歷史交手：2014 年起的世界賽與 MSI，一次整理在 `data/history.json`（需要重建時手動執行「重建歷史戰績」）。
- 隊伍改名／收購對照：`scripts/teams.json`。
- 勝率參考：國際賽 Elo 實力分數 + 交手紀錄小幅修正，說明見網站「資料與方法」。
